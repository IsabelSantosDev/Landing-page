## 🚀 Landing Page — Consultoria Digital

Landing page focada em conversão, desenvolvida com HTML, CSS e JavaScript, ideal para pequenos negócios e profissionais autônomos que desejam uma presença online clara, rápida e profissional.

## 🎯 Objetivo do projeto

Criar uma landing page:

Simples e elegante

Focada em conversão (gerar contatos no WhatsApp)

Responsiva e rápida

Fácil de adaptar para qualquer nicho

Este projeto foi pensado para demonstrar boas práticas de UI, UX e estrutura de páginas de venda.

## 🖥️ Tecnologias utilizadas

HTML5 — Estrutura semântica

CSS3 — Layout moderno, responsivo e animações suaves

JavaScript (Vanilla) — Interações e redirecionamento para WhatsApp

Google Fonts (Poppins)

## ✨ Funcionalidades

✔️ Layout moderno e clean

✔️ Design responsivo (desktop e mobile)

✔️ Botão com redirecionamento direto para WhatsApp

✔️ Mensagem automática no WhatsApp

✔️ Animações suaves ao rolar a página

✔️ Hover effects e micro-interações

✔️ Scroll suave entre seções
